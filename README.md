### [NAVIA](https://github.com/TacosAlPastorMX/SINAIT-APP) — Accessible Campus Navigation
Indoor/outdoor navigation app for TecNM Campus, targeting students with visual or mobility impairments. Real-time routes via Firebase Firestore with BLoC architecture.

`Flutter` `Dart` `Firebase Firestore` `BLoC` `Android Studio`

---

### [CARPOOL](https://github.com/SantiagoPro1/CARPOOL) — University Carpooling Platform
3-layer REST architecture with institutional authentication (`@colima.tecnm.mx`), route-matching engine, reputation system, and SQL Injection prevention via Eloquent ORM.

`Laravel` `MySQL` `REST API` `PWA` `Node.js` `CSRF`

---

### [GEOMA](https://geomas.softr.app/) — AgTech Satellite Monitoring · 🥇 Techstars 2024
Combines satellite imagery (Sentinel-2, Landsat 8, WorldView-3) with AI models for early HLB detection in lime crops and irrigation optimization (−30% water usage projected). Freemium/Basic/Premium SaaS model.

`Frontend` `AI / Predictive models` `Satellite imagery` `SaaS`

---

### Dragonbin — Tourism Web App · 🥇 IAFest 2023
Multi-page tourism promotion site for the state of Colima (Ciudad de Colima, Manzanillo, Coquimatlan). 1st place in the Tourism track at IAFest 2023, TecNM Campus Colima.
